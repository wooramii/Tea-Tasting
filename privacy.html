차곡으로 돌아가기

개인정보처리방침

시행일: 2026년 11월 19일

차곡 Tea Library는 차 제품과 날짜별 테이스팅 기록을 관리하는 웹 프로그램입니다. 이 안내는 현재 배포된 1차 버전의 데이터 처리 방식을 설명합니다.

입력 정보와 이용 목적

사용자가 입력한 제품명, 브랜드, 바코드, 구매정보, 테이스팅 날짜, 관능점수, 노트, RTD 측정값, 이미지·구매 링크를 저장·조회·검색·비교하는 데 사용합니다. Google 비밀번호는 앱이 수집하지 않습니다. 별도 회원명부를 만들기 위해 이메일·프로필을 요청하지 않습니다.

기기 저장과 Google 연결

Google 연결 전 기록은 현재 브라우저의 로컬 저장소에 보관됩니다. 같은 브라우저와 기기를 함께 사용하는 사람에게 노출될 수 있으며, 브라우저 데이터 삭제 시 사라질 수 있습니다. Google 연결 시 사용자가 허용한 계정의 Drive에 전용 Google 스프레드시트를 생성하거나 기존 전용 파일을 찾아 기록을 읽고 저장합니다. 기기 기록은 자동 전송하지 않으며 사용자가 백업 불러오기를 선택하면 해당 기록을 저장합니다.

Google 접근 권한은 https://www.googleapis.com/auth/drive.file입니다. 앱이 생성했거나 앱에 접근을 허용한 파일을 대상으로 하며, Drive 전체 파일에 대한 접근 권한을 요청하지 않습니다. 연결용 접근 토큰은 현재 탭의 메모리에서 사용하고 앱 코드가 로컬 저장소에 영구 보관하지 않습니다.

보관·공유 및 외부 서비스

현재 버전에는 테이스팅 기록을 모으는 별도 운영자 데이터 서버가 없습니다. 사용자가 시트나 백업 파일을 직접 공유하지 않는 한, 앱이 다른 사용자에게 기록을 자동 공개하지 않습니다. Google 연결 시 기록은 Google 서비스에 전송·저장됩니다. 웹사이트 파일은 GitHub Pages에서 제공되므로 GitHub는 접속 과정에서 자체 정책에 따라 접속 정보를 처리할 수 있습니다.

제품 이미지 주소를 등록하면 브라우저가 해당 이미지 제공 서버에 요청합니다. 구매 링크를 누르면 해당 사이트로 이동합니다. 외부 서비스에는 각 서비스의 개인정보처리방침이 적용됩니다. 현재 앱 코드에는 광고·행동분석 도구와 AI 외부 분석 전송 기능이 없습니다.

보관 기간·삭제·연결 해제

기기 기록은 사용자가 해당 사이트의 브라우저 저장 데이터를 삭제할 때까지 남습니다. Google 시트 기록은 사용자가 Drive에서 해당 파일을 삭제하고 필요한 경우 휴지통을 비울 때까지 Google 측 보관 정책에 따라 유지됩니다. 앱의 연결 해제는 시트 파일이나 기기 기록을 삭제하지 않습니다. 백업 파일은 다운로드한 사람이 직접 관리·삭제해야 합니다.

앱 화면의 연결 해제 또는 Google 계정의 연결 관리에서 접근 권한을 철회할 수 있습니다. 사용자는 자기 시트의 기록을 조회·수정·삭제할 수 있습니다.

Google 사용자 데이터 이용 제한

Google API를 통해 받은 정보는 사용자에게 요청받은 기록 관리 기능을 제공하는 데만 사용합니다. 이를 판매하거나 광고 타기팅·신용평가·범용 AI 모델 학습에 사용하지 않습니다. Google API로 받은 정보의 이용과 다른 앱으로의 전송은 제한적 사용 요건을 포함한 Google API Services User Data Policy를 준수합니다.
