Tavily 웹 검색 추가 · 2026-11-20

Tavily 연결 안내. 검색 후보를 한 번 선택하면 확인된 제품명·브랜드·용량·원재료명·이미지·판매 링크·판매가격을 제품정보 칸에 채웁니다. 원문에 없는 정보는 비워 둡니다. 바코드는 원문의 번호 항목이 일치한 후보만 표시합니다. 이미지는 해당 후보 원문의 제품 이미지로 확인되는 것만 사용합니다.

로그인 표시·새로고침·입력 초기화

Google 연결 후에는 연결 버튼을 숨기고 상태만 표시합니다. 상단 차곡 문구를 누르면 Google 연결을 유지하면서 입력 화면을 초기화하고 최신 기록을 읽습니다. 미저장 입력은 확인창에서 비울지 선택합니다. 브라우저의 F5·Ctrl+F5 또는 탭을 다시 여는 동작은 페이지 전체를 다시 불러오므로 Google 재연결이 필요합니다. 접근 토큰 자체가 만료되어도 다시 연결해야 하며 입력은 유지됩니다.

제품정보의 「입력 초기화」는 제품과 관능평가의 미저장 입력을 비웁니다. 「평가 초기화」는 선택한 제품을 유지하고 새 날짜의 평가만 준비합니다. 저장된 제품과 기록은 지우지 않습니다.

지금 바로 해보기

  1. 검색 공간에 제품명·브랜드·분류·바코드 중 아는 정보를 입력하고 「조회」를 누릅니다. 바코드가 있으면 번호 일치를 우선합니다. 카메라로 인식해도 자동 조회합니다.
  2. 실제 제품과 같은 후보를 선택합니다. 가운데 제품정보와 이미지가 채워집니다. 분류를 선택하고 원재료명·포장·이미지 등을 대조합니다. 못 찾으면 「제품 직접 등록」으로 입력하세요.
  3. 제품정보 저장을 누릅니다. 아직 마시지 않았어도 저장할 수 있으며 평가 횟수는 늘지 않습니다.
  4. 마신 날 오른쪽에서 날짜와 관능평가를 입력하고 테이스팅 기록 저장을 누릅니다.
  5. 나중에는 아래 컬렉션에서 제품을 선택하고 「제품정보 / 테이스팅 추가」를 누릅니다. 같은 제품의 평가가 날짜별로 모입니다.
  6. 「백업 받기」로 제품과 평가를 함께 보관하세요. 브라우저 데이터 삭제·시크릿 모드 종료 시 기기 기록이 사라질 수 있습니다.

제품명·바코드로 정보 불러오기

조회에는 내 저장 제품·Open Food Facts·설정된 Tavily를 사용합니다. 조회와 후보 선택만으로 저장되지는 않습니다. 후보 선택 시 새 제품정보를 채우며, 다른 제품의 기존 원재료나 이미지가 섞이지 않도록 없는 값은 비웁니다. 미저장 입력이 있으면 교체 전에 확인합니다. 관능점수·추출조건·Brix·pH·산도는 제품정보로 자동 추정하지 않습니다.

조회가 실패해도 입력은 유지합니다. 원문에 정보가 없는 제품, 최근 출시품, 읽을 수 없는 웹 페이지는 직접 보완해야 합니다. 조회 결과는 실제 포장과 대조하세요.

GitHub 배포

  1. GitHub에서 새 저장소를 만듭니다. 예: tea-library.
  2. 화면용 압축파일 안의 24개 파일을 저장소 최상위에 올립니다. 기존 저장소의 config.js는 그대로 둡니다. index.html이 저장소 첫 화면에서 보여야 합니다.
  3. 저장소의 Settings → Pages → Deploy from a branch → main → /(root) → Save를 선택합니다.
  4. 배포가 끝나면 Pages에 표시되는 실제 주소를 엽니다. 보통 https://사용자명.github.io/tea-library/ 형태입니다.
  5. 이 링크를 다른 사람에게 주면 각자 기기 저장 모드로 바로 사용할 수 있습니다.

개인 Google 계정 연동: 배포 후 한 번 설정

앱 소유자만 아래 설정을 합니다. 방문자는 설정할 필요 없이 로그인·권한 허용만 하면 됩니다. 회사 계정은 조직 정책으로 차단될 수 있습니다.

  1. Google Cloud Console에서 프로젝트를 만듭니다.
  2. API 및 서비스 → 라이브러리에서 Google Sheets API와 Google Drive API를 각각 사용 설정합니다.
  3. Google Auth Platform에서 앱 이름, 연락 이메일을 설정합니다. 잠재고객은 외부(External)로 선택합니다.
  4. 데이터 액세스 권한으로 https://www.googleapis.com/auth/drive.file을 추가합니다. Drive 전체 접근 권한은 선택하지 않습니다.
  5. 클라이언트 → OAuth 클라이언트 만들기 → 웹 애플리케이션을 선택합니다. 승인된 JavaScript 원본에 https://사용자명.github.io를 입력합니다. 저장소 경로는 원본에 넣지 않습니다. 로컬 테스트용으로 http://localhost:8080도 추가할 수 있습니다.
  6. 발급된 클라이언트 ID를 config.js의 빈 따옴표 안에 넣고 GitHub에 업데이트합니다. 클라이언트 보안 비밀은 사용하지 않습니다.
  7. 테스트 중에는 본인의 Google 계정을 테스트 사용자로 등록합니다. 차곡에서 Google로 연결 → 권한 허용 → 기록 저장을 시험합니다.
  8. 전용 시트 차곡 Tea Library가 본인 Drive에 생성됩니다. 이 파일을 공개로 공유하지 마세요.
  9. 다른 사람에게 제한 없이 제공하려면 잠재고객의 게시 상태를 프로덕션으로 변경하고 Google이 요구하는 앱 정보·브랜드·도메인 관련 절차를 완료해야 합니다. 테스트 상태는 등록된 테스트 사용자만 연결할 수 있습니다. 실제 허용 여부는 계정과 Google 심사·정책에 따릅니다.

시트에서 직접 수정하기

기존 Records 탭과 열 순서는 유지합니다. 연결 시 맨 뒤에 기록유형, 제품ID, 판매가격, 판매가격확인일 열을 추가합니다. 기존 행은 그대로 날짜별 평가로 읽습니다.

기록유형=제품 행은 제품정보이며 테이스팅 날짜·점수는 비워 둡니다. 테이스팅 행은 날짜별 평가입니다. 같은 제품은 제품ID로 연결합니다. 제품정보를 다시 저장하면 이전 내용을 덮어 지우지 않고 같은 제품ID로 새 제품정보 행을 추가합니다. 앱은 기록시각이 가장 최근인 제품 행을 사용합니다.

제품정보를 시트에서 수정하려면 해당 제품ID의 최신 제품 행을 수정하세요. 평가값은 해당 날짜의 테이스팅 행에서 수정하세요. id, 제품ID, 제목 행과 열 순서는 유지합니다. 연결 후 60초마다 갱신하거나 「새로고침」을 눌러 반영합니다. 날짜 필터는 평가 날짜 기준이므로 평가가 없는 제품은 날짜 필터 사용 중 제외됩니다.

기기 기록을 Google로 옮기기

  1. Google 연결 전 「백업 받기」를 누릅니다.
  2. Google로 연결합니다.
  3. 「백업 불러오기」에서 방금 받은 파일을 선택합니다. ID가 같은 기록은 중복 추가하지 않습니다.

1차 버전의 범위

가능: 제품정보 별도 저장, 후보 선택 자동 입력과 이미지 미리보기, 날짜별 테이스팅, 7종 관능강도 1~9점 또는 미평가, RTD Brix·pH·적정산도, 컬렉션 검색·날짜 필터, 관능 수치 유사도, 백업, 개인 Google 시트 연결.

사진 파일 업로드·사진 속 제품 인식·AI 의미 검색은 포함하지 않습니다. 판매가격은 조회 당시 원문 표기이며 실제 구매가격·최저가나 실시간 가격을 보장하지 않습니다. 관능 유사도는 공통 평가 항목의 거리이며 개발 성공 확률이 아닙니다.

바코드가 흐리거나 잘 읽히지 않을 때

  1. 카메라를 열면 지원 장치에서 연속 자동초점을 먼저 요청합니다. 한 번 자동초점만 지원하면 그 방식을 요청합니다. 카메라가 제공하지 않는 초점 기능은 소프트웨어로 만들 수 없습니다.
  2. 「현재 실제 영상」의 해상도를 확인하세요. 기본값은 고해상도를 우선 요청합니다. 목록에서 해상도를 바꾸면 실제 적용값을 다시 표시합니다. 범위에 포함된 해상도라도 가로·세로 조합은 지원하지 않을 수 있으며, 실패하면 기존 영상으로 계속 인식합니다.
  3. 자동초점이 맞지 않으면 「수동 초점」을 선택하고 슬라이더로 선명도를 조절합니다. 슬라이더를 놓으면 적용됩니다. 지원되지 않으면 초점 제어 미지원으로 표시됩니다.
  4. 카메라 해상도를 바꾸면 인식 엔진도 새 프레임 크기로 다시 시작합니다. 화면 크기만 늘리는 디지털 확대는 하지 않습니다. 가까이 붙이지 말고 가는 줄과 흰 틈이 선명해지는 거리를 찾으세요.

외부 검색 범위

「조회」는 내 기록·Open Food Facts와 설정된 Tavily에서 제품정보를 찾습니다. 바코드 검색은 번호 일치 증거가 있는 후보만 표시합니다. Google·네이버·쿠팡 버튼은 각 검색 사이트를 엽니다. 「바코드 조회」는 입력한 바코드가 채워진 GS1 페이지를 새 탭에서 열며 결과를 자동 입력하지 않습니다. 「복사」는 숫자를 클립보드로 복사하며 검색이나 저장은 하지 않습니다.

GS1 Korea의 자동 데이터 연동은 바코드 정보 제휴사업의 계약·이용 조건 협의와 API 인증정보가 필요합니다. 일반 웹 조회 기능은 API 사용권한을 대신하지 않습니다. GS1 Korea 제휴 안내

Edge에서 카메라가 열리지 않을 때

  1. 배포 주소를 열고 카메라 버튼을 누릅니다. 권한 창이 뜨면 사용할 카메라 접근을 허용하세요.
  2. 차단했다면 Edge 주소창의 사이트 정보 → 이 사이트에 대한 사용 권한 → 카메라 설정을 확인하고 페이지를 새로고침하세요.
  3. Windows 설정 → 개인정보 및 보안 → 카메라에서 카메라 접근과 데스크톱 앱의 카메라 접근을 확인합니다. 회사 정책으로 잠겨 있으면 IT 담당자에게 확인하세요.
  4. 카메라를 찾지 못하면 USB 웹캠·노트북 카메라 연결을 확인하고, 사용 중이라는 안내가 나오면 Teams·Zoom 등에서 카메라를 끕니다.
  5. 카메라가 여러 개면 스캔 창에서 선택합니다. 인식 모듈 오류라면 zxing-browser.min.js 파일도 GitHub에 올렸는지 확인하세요.

인식은 기기에서 처리하며 카메라 영상을 서버로 업로드하지 않습니다. 닫기·다른 탭으로 이동·페이지 종료 시 카메라를 중지합니다. 인식 후에는 바코드로 제품정보를 조회합니다.

데이터 처리

Google 비밀번호를 차곡이 받지 않습니다. 연결 토큰은 현재 탭 메모리에만 보관하며, 새로 열면 다시 연결합니다. 연결 해제는 시트를 지우지 않습니다. 기기 저장 기록은 이 브라우저에 남습니다. 제품 이미지 URL을 입력하면 이미지는 해당 주소에서 불러옵니다. 회사 기밀·개발정보를 개인 계정에 저장하기 전 회사 정책을 확인하세요.
